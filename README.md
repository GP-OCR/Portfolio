# Portfolio

Portfolio personnel de Gaetan Pruvot, testeur logiciel en formation OpenClassrooms (projet 12).

Site statique : HTML, CSS, JavaScript et données JSON (`data/skills.json`, `data/portfolio.json`).

## Prérequis

- Un navigateur moderne
- Python 3 (pour le serveur local)

## Lancement en local

```bash
python3 -m http.server 8123
```

Ouvrir [http://localhost:8123](http://localhost:8123).
